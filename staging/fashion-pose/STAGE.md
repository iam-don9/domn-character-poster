# 时尚摆拍

## 演出原子

角色**为镜头而摆**：身体线条有设计感、四肢讲究延伸方向，像时装大片的一页。**张力可高可低**——从雕塑式的静，到跃起失衡的炸，都是摆拍。

> ⚠️ **不要把摆拍等同于"静气"。**
> 时尚 editorial 里有大量**高张力**姿态：跃起、织物飞扬、极限拉伸、反向扭身、失衡重心。**先问"这个角色该配哪一端"，不要默认选静的那端。**

## 输入变量

- 角色：{{角色名}}
- 能力类型：{{技术 / 商业 / 街头 / 自定义}}
- **张力档**：{{低（雕塑式静态）/ 高（跃动失衡）}}
- 画幅比例：3:4

## 演出基因

### 姿态与肢体语言（两端都成立，按张力档选）

**低张力端 · 雕塑式**

- 三角造型：手 / 腿 / 头形成明确的三角关系，线条有设计感。
- 重心落一条腿，另一腿前伸或交叉；脊背挺直或弯成 S 形；肩线一高一低。

**高张力端 · 跃动式**

- 身体**离地或半离地**（跃起 / 单足点地 / 被风带起）。
- **反向扭身**：上身与下身朝向相反，脊椎拉出长弧。
- **织物 / 头发 / 披风大幅飞扬**，形成方向明确的动势面。
- 四肢极限拉伸（一臂完全展开、腿抬至极限），重心明显失衡却保持优雅。

**两端共用**

- 四肢讲究**线条的延伸方向**，不随意摆放。
- **判据**：这条线条若被一条直线替代，画面会不会塌？会 → 它在承重。

### 手部动作

扶腰 / 撩发 / 拉衣领 / 插袋 / 抬手 / 指尖轻触唇 / 拎包 / **甩袖 / 撑地 / 抓握衣摆** —— 手是**造型的一部分**，位置经过设计。

### 表情与视线

- 低张力端：冷、克制，直视镜头或下巴微抬看向远处。
- 高张力端：**眼神有方向感与攻击性**（看向动势指向或镜头），可带紧绷。
- 两端都不夸张；不张嘴大笑。

### 情境

秀场 / 影棚 / 街拍 / 极简建筑前 / **风大的户外 / 雨中**。高张力端优先选**有风、有雨、有扬尘**的环境——它们给动势一个物理理由。

### 机位与角度

- 低张力端：平视或略低（拉长腿部比例），**无透视畸变**。
- 高张力端：**可低角度仰拍或斜角**（增强跃起与失衡的张力），允许适度透视夸张。
- 全身或 3/4 身为主。

## 单姿态（主视觉用）

- 低张力端：走位 / 回眸 / 坐姿 / 靠墙 / 特写
- 高张力端：跃起 / 甩袖转身 / 撑地低伏 / 逆风站定 / 半空回眸

**选 1。**

## 序列逻辑（人物设定图用）

- 低张力端：**走位 → 回眸 → 坐姿 → 面部特写**（杂志内页式）
- 高张力端：**蓄势 → 跃起 → 滞空顶点 → 落地回眸**

## 与海报风格的适配

| 海报风格 | 适配 |
|---|---|
| `magazine-cover` | **天然配对**——摆拍 + 刊名区就是一本刊 |
| `minimal-editorial` | 可配——大留白衬托身体线条（低张力端更顺） |
| `cinematic-onesheet` | 可配——深色基调 + 戏剧光给高张力端加成 |
| `hud-keyart` | **可配**——高张力端与 HUD 的能量语言同向；若用低张力端，把 HUD 密度降到「极简」档即可 |

## 生成前检查

- **张力档定了吗**（低 / 高）？
- 手 / 腿 / 头是否有明确的造型关系？
- 高张力端：是否离地或半离地、是否反向扭身、织物是否飞扬？
- 视线是否有方向感？
- 低张力端：是否无透视畸变？

## 演出特有禁用项

- 不要生活化的随意感（那是日杂）。
- 不要影棚白底证件照式站姿。
- **不要默认选静的那一端**——先问张力档。
- 不要夸张表情、不要张嘴大笑。
- 不要泛词：高级 / 气质 / 气场——改写为具体的线条与重心。
