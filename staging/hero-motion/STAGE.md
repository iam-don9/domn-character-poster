# 高能动作

## 演出原子

角色处在**运动的顶点**：冲刺中 / 跃起滞空 / 能量爆发的瞬间，四肢舒展有张力、重心偏移、衣摆发梢被风带起，画面读得出"他正要去哪儿"。

## 输入变量

- 角色：{{角色名}}
- 能力类型：{{技术 / 火力 / 街头 / 元素 / 自然 / 自定义}}
- 画幅比例：3:4

## 演出基因

### 姿态与肢体语言

- **身体处于运动中**，不是站定——重心偏移、躯干扭转、四肢不对称开合。
- 前腿发力后腿蹬伸，或双腿收拢滞空。
- 衣摆 / 披风 / 发梢被风与惯性带起，形成方向明确的动势线。
- 张力方向单一明确（朝一个方向冲），不左右对拉。

### 手部动作

触发 / 释放 / 握武器 / 推 / 伸 / 比手势——**六选一**，手必须正在做一件事。

### 表情与视线

- 表情与动作一致：发力时的咬紧、释放时的专注、滞空时的凝视。
- 视线朝向**动作指向**或镜头；不涣散。

### 情境

高能瞬间——冲刺途中、落地前一帧、能量外放中、破墙而出。背景服务于动势，不抢戏。

### 机位与角度

- **低角度仰拍**：增强高度与压迫（跃起 / 冲刺首选）。
- **平视**：横向冲刺时用，动势线横穿画面。
- **轻微俯拍**：下落 / 落地瞬间。
- 透视强度按动作方向给（冲向镜头 = 强透视）。

## 单姿态（主视觉用）

悬空 / 跃起 / 街跳 / 蹲起 / 浮现 / 冲刺 —— **选 1**。

## 序列逻辑（人物设定图用）

**起势 → 爆发 → 滞空 → 签名定格**（4 格）。

- 起势：重心下沉，蓄力姿态
- 爆发：蹬地离地，动势线最强
- 滞空：四肢舒展的顶点帧
- 签名定格：最可截图的那一帧

## 与海报风格的适配

| 海报风格 | 适配 |
|---|---|
| `hud-keyart` | **天然配对**——动态 + 巨型标语 + HUD 是一套语言 |
| `cinematic-onesheet` | 可配——动态主视觉 + 标题块 |
| `magazine-cover` | 可配，但刊名区会压缩动势空间 |
| `minimal-editorial` | **冲突**——那个要静与留白，高能动作会把画面撑满 |

## 生成前检查

- 是否读得出"他正要去哪儿"（动势方向明确）？
- 重心是否偏移、不是站定？
- 手是否正在做一件事？
- 机位角度是否与动作方向匹配？

## 演出特有禁用项

- 不要静态站姿摆拍、不要"漂浮"（没有重心的悬空）。
- 不要泛词：帅气 / 炫酷 / 强烈的动感 / 速度感极强——改写为具体动作 + 重心 + 机位。
- 不要左右对拉的对抗式构图（那是战斗类）。
- 不要四肢全对称的"跳伞式"姿势。
