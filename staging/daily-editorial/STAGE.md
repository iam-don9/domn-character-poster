# 日杂动作

## 演出原子

角色在做一件**日常小事**：手上有活、注意力在自己的事上，不看镜头。姿态松弛、重心自然、有生活气，像被随手拍下的一帧，不是摆出来的。

## 输入变量

- 角色：{{角色名}}
- 能力类型：{{技术 / 街头 / 自然 / 自定义}}
- 画幅比例：3:4

## 演出基因

### 姿态与肢体语言

- **重心落在一条腿上**，另一条腿放松；肩膀不平齐（自然的不对称）。
- 身体略前倾或侧靠（靠墙 / 靠桌 / 靠窗框）。
- 四肢放松，不做三角造型；避免一切"设计感线条"。
- 姿态读得出"正在做某件事"，不是"正在被拍"。

### 手部动作

拿杯子 / 翻书页 / 拨头发 / 插兜 / 整理衣角 / 撑下巴 / 拎包 / 系鞋带 —— **正在用**，不是摆着。

### 表情与视线

- **不看镜头**（看窗外 / 看手里的东西 / 看脚下），或极轻的、不经意的笑。
- 表情松弛，眉与嘴角都不使劲。

### 情境

日常生活切片——午后窗边、街角、通勤路上、咖啡馆、自家厨房、雨后的屋檐下。环境有生活痕迹（杯子、书、包、植物）。

### 机位与角度

- **平视或略高**（略高显柔和）。
- 中景为主（半身到七分身），不追求全身完整。
- 轻微手持晃动感 / 自然光方向明确（窗光、天光）。

## 单姿态（主视觉用）

**生活动作的一帧**——不是摆拍。从"手部动作"里挑一个正在进行的动作。

## 序列逻辑（人物设定图用）

**生活四格切片**（4 格）：四件不同的小事 / 四个不同日常场景，**同一个人、同一套光**。

- 例：窗边看书 → 厨房倒水 → 门口系鞋带 → 街角回头
- 四格之间只换动作与场景，**光的方向与色温保持一致**（同一段时间内）。

## 与海报风格的适配

| 海报风格 | 适配 |
|---|---|
| `minimal-editorial` | **天然配对**——留白 + 生活感，气质同源 |
| `magazine-cover` | 可配——刊名区 + 生活切片 |
| `cinematic-onesheet` | 可配，但深色基调会压掉日杂的通透 |
| `hud-keyart` | **冲突**——HUD 与高饱和会把生活感碾平 |

## 生成前检查

- 是否读得出"正在做某件事"，而不是"正在被拍"？
- 肩膀是否不平齐、重心是否在一条腿上？
- 是否不看镜头？
- 光是否只有一个自然光源方向？

## 演出特有禁用项

- 不要影棚摆拍感、不要硬凹姿势、不要三角造型。
- 不要直视镜头的模特脸（除非用户明确要）。
- 不要超现实光效、不要强对比戏剧光。
- 不要泛词：自然 / 随性 / 高级感——改写为具体的动作 + 重心 + 视线。
