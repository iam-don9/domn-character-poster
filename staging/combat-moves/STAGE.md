# 战斗招式

## 演出原子

角色**正在出手或刚收招**：拧腰转胯、重心下压或前倾，四肢与兵器形成一条发力链，读得出"这一击打在哪儿"。是打斗中的**签名帧**，不是连续动作。

## 输入变量

- 角色：{{角色名}}
- 能力类型：{{技术 / 火力 / 街头 / 元素 / 自定义}}
- 兵器载体：{{刃类 / 钝拳脚 / 枪棍 / 能量 / 体术 / 机械 / 兽形}}
- 画幅比例：3:4

## 演出基因

### 姿态与肢体语言

- **发力瞬间**：拧腰转胯、重心下压（蓄力）或前倾（命中）、肩胯反向。
- 发力链可见：脚 → 腰 → 肩 → 手，方向一致。
- 招式类型先定：投射 / 追踪 / 范围 / 近身 / 突袭 / 蓄力大招。
- 衣摆、武器尾迹、发丝带出方向明确的**动势残影**。

### 手部动作

握持兵器 / 出拳 / 结印 / 释放能量 / 格挡 / 反手 —— 手必须落在招式的发力点上。

### 表情与视线

- 锁定目标的冷峻；视线朝向**对手或招式指向**。
- 不喊叫、不夸张——压住情绪比外放更有压迫。

### 情境

交手中 / 蓄力中 / 收招瞬间。环境可有破坏痕迹（碎裂、扬尘、切痕）作反馈。

### 机位与角度

- **低角度仰拍**：增强压迫（对峙 / 蓄力）。
- **斜角（荷兰角）**：失衡与危险感（命中瞬间）。
- **极近特写**：兵器碰撞点 / 拳锋（局部张力）。

## 单姿态（主视觉用）

起手 / 命中 / 收招 / 定格 —— **选 1**。

## 序列逻辑（人物设定图用）

**起手 → 连击 → 收招 → 签名定格**（4 格）。

- 起手：蓄力姿态，重心下压
- 连击：出手瞬间，动势最强
- 收招：惯性带身形缓转落定
- 签名定格：最可截图的一帧

## 招式取词（取类型与强度，**不取成品招**）

| 载体 | 动词 |
|---|---|
| 刃类 | 旋斩、连斩、居合斩、回马斩、撩刃、挑刺、拖刀、削斩、格挡反刺、交叉下斩、飞斩气刃 |
| 钝 / 拳脚类 | 抡砸、横扫、崩拳、贯手、震地重击、掌底轰击、回旋踢、下压踢、膝顶、肘击、肩撞 |
| 枪 / 棍类 | 突刺、点扫、拦拿扎、横扫堂、托劈、回马枪、抖枪花 |
| 能量 / 魔法 | 迸发、湮灭、灼穿、电弧窜行、冲击波外扩、粒子束贯穿、聚能过载、光刃斩空 |
| 体术 / 身法 | 瞬身、闪现、残影分身、踏空、蹬墙翻越、侧空翻闪避、借力回旋、拧腰转胯 |
| 机械 / 机甲 | 兵装展开、推进突进、装甲冲撞、齐射覆盖、机械臂钳甩 |
| 巨兽 / 兽形 | 獠牙咬合、尾扫、翼压、鬃毛炸刺、扑撞、吐息、践踏 |

**质感强化词**：寒光乍现、撕裂空气、刀身震颤嗡鸣、破空锐啸、气场暴涨、残影拖尾、骨节爆响、衣袂猎猎。

> ⚠️ **招式必须结合当前角色现造**——取的是"类型与强度"，不是"成品招"。同一个"瞬身俯冲"，机兽是獠牙面甲喷能量坠击、剑客是居合坠斩刃光先到。

## 生成前检查

- 是否读得出"这一击打在哪儿"？
- 发力链是否方向一致（脚→腰→肩→手）？
- 招式是否结合了当前角色（不是通用成品招）？
- 是否没有泛词（打 / 攻击 / 挥舞 / 帅气 / 华丽 / 震撼）？

## 演出特有禁用项

- **泛词黑名单**：打 / 攻击 / 挥舞 / 移动 / 冲过去 / 强烈 / 震撼 / 迅猛 / 炸裂 / 压迫感 / 帅气 / 华丽 / 酷炫 —— 一个都不许出现。
- 不要静态站定（那是摆拍）。
- 不要"空放特效"——特效必须有对应的发力源。
- **不要回合节奏 / 慢拍 / 时间码**（那是视频逻辑，静态海报只要签名帧）。
