# 海报视觉原子生成

把一种**海报排版风格**，转成一份**可复用的结构化原子**（`STYLE.md` + `META.md`），供本任务及以后复用。

**原子只管海报怎么排**——版式、字体、图文关系、色彩氛围、装饰。**不写角色成像、不写角色长相**（那是参考图与角色锚点卡的事）。

## 心法（来自 huashu）

- **三槽位**：主体 / 风格 / 媒介——每个槽位都要填一个模型熟知的高频名字；填不上的用结构化描述补足。
- **真名锚点替代形容词**：1 个真名 > 5 个形容词（"A24 海报质感" > "editorial illustration with film grain"）。
- **结构性 vs 气质性二分**：结构性强的风格（视觉元素可枚举）短 prompt 即可；气质性强的风格（难言传的氛围）**必须补结构化描述**。
- **看图只写看到的**：不追加图上没有的风格词。
- **只写稳定项**：跨参考图都成立的才进原子；只在一张上出现的，标 `variable`，不进原子。
- **拒绝平庸安全**（huashu 的探索模式）：**不要"安全的好看"。** 每个原子都要能答一句「**为什么这是最抓眼球、最有张力的形式**」；答不出，说明它只是"看着还行"。
- **土味清单**（写原子时逐条对照，命中即返工）：平光 / 正面居中 / 通用渐变背景 / 同色系堆叠 / **3D 立体字** / 无冷暖对撞。
- **专属检验**：把风格名换掉，这个原子还成立吗？**成立 → 它不是这个风格的特征 → 删。**

## 真名锚点与 nameplate 陷阱（huashu）

**允许在 `style_anchors` 里用真名锚定**（设计师 / 工作室 / 产品品牌 / 电影调性），这是最高效的压缩。

但**出版物 / 媒体品牌名是红灯**——`The Economist 风格` / `WSJ 风格` / `Field Notes 风格` 这类，模型会**主动把品牌名画到图左上角**当真实报头，并整体跳到英文排版。

- 红灯判据：prompt 里出现「××杂志 / 报纸 / 刊物 风格」，或真名本身是出版物 / 媒体品牌。
- 修复：删掉出版品牌真名，改描述性词（"印刷质感 / 编辑插画感"），并在负向里写死 `无外文品牌名水印，无左上角 nameplate`。
- 低风险真名：设计师人名（Dieter Rams）、产品 / 公司品牌（Anthropic / Apple / MUJI）——它们的设计哲学本身就是锚定目标，不存在 nameplate 误植。

## 读图六维（判海报排版风格）

逐项写"看到了什么"，不写"感觉像什么"：

| 维度 | 读什么 |
|---|---|
| 版式 | 标题位置 / 信息层级 / 留白策略 / 分区方式 |
| 构图 | 主体与文字的空间关系 / 主视觉落点 |
| 字体 | 字族气质（衬线 / 无衬线 / 手写）/ 字重 / 字级层次 |
| 图文关系 | 文字如何与主体咬合（压暗部 / 贴边 / 穿插） |
| 色彩系统 | 背景与标题的配色逻辑（**不含角色配色**） |
| 装饰元素 | 色块 / 线 / 编号 / 边饰 / 其面积配额 |

## 输出格式

### STYLE.md

```markdown
# {风格名}

## 视觉风格原子
{一句话：这是什么排版风格的海报}

## 输入变量
- 角色：{{角色名}}
- 角色设定摘要：{{...}}
- 画幅比例：3:4
- 语言：English
- 点缀：{{不使用 / ...}}

## 风格基因
### 版式
### 构图与分区
### 字体
### 图文关系
### 色彩系统
{背景 / 标题 / 装饰的配色逻辑；强调色最多一种。**不写角色配色**}

## 生成前检查
{3–6 条自检；**必含一条：「为什么这是最抓眼球、最有张力的形式？」**}

## 风格特有禁用项
{对齐相邻风格的必禁词，不随手罗列}
```

### META.md

```yaml
id: {style-id}
name: {中文风格名}
input_modes: [text, image]
subjects: [person]
outputs: [keyvisual, sheet]
default_ratio: "3:4"
required_fields: [角色参考图, 角色设定]
optional_fields: [文字层]
source: styles/{style-id}/STYLE.md
style_anchors: []
keyvisual_shape_adaptation: []
sheet_shape_adaptation: []
must_preserve: []
avoid_when_applying_to_keyvisual: []
avoid_when_applying_to_sheet: []
```

每个列表填**可观察、可检验**的陈述句。

## 三条硬约束

1. **原子只写海报排版，不写角色**——角色的成像与长相归 `anchor-card.md`，一个字段都不许进原子。
2. **不写"模仿 / 复刻"**——用"××风格"指代视觉方向，不写"复刻某作品 / 某角色"。
3. **可用真名锚点，但避开 nameplate 陷阱**——出版物 / 媒体品牌名一律不用。
