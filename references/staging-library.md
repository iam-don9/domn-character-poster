# 演出库规范

演出库 = `staging/{stage-id}/{STAGE.md, META.md}`。
**公共规则（只收用户教的 / 任务链路 / 入库流程）见 `library-rules.md`。**

## 装什么 / 不装什么

**装**「角色在做什么」——姿态与肢体语言 / 手部动作 / 表情与视线 / 情境 / 机位角度。

**不装**：

- 角色成像与长相 → 归参考图（`anchor-card.md`）
- 海报版面 / 字体 / 图文关系 / 背景色彩 / 装饰 → 归 `styles/`

> 命名用 `STAGE.md`（不是 `STYLE.md`），与海报风格库区分开。

## 命中判定

按 `staging-atom.md` 的**读素材六维**（姿态与肢体语言 / 手部动作 / 表情与视线 / 情境 / 机位与角度 / 序列逻辑）逐项比对，**≥5 项吻合**才算命中。
