# 画风库规范

画风库 = `styles/{style-id}/{STYLE.md, META.md}`。
**公共规则（只收用户教的 / 任务链路 / 入库流程）见 `library-rules.md`。**

## 装什么 / 不装什么

**装**：版式 / 构图分区 / 字体 / 图文关系 / 背景色彩系统 / 装饰元素。

**不装**：

- 角色成像与长相 → 归参考图（`anchor-card.md` 的成像锁定）。真人 / 3D / 2D 是**角色成像**，**不进库**。
- 角色在做什么 → 归 `staging/`。

## 命中判定

按 `style-atom.md` 的**读图六维**（版式 / 构图 / 字体 / 图文关系 / 色彩系统 / 装饰元素）逐项比对，**≥5 项吻合**才算命中。
只差色彩一项 → 算命中，色彩按当前任务覆写。

**注意**：海报风格**不是**从角色参考图里匹配出来的——参考图只管角色成像。若用户额外给了一张**海报 / 版式参考图**，那才按它现生成原子。
