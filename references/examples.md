# few-shot 示例

> 以下为**示意示例**（演示填法，非实测结果）。角色、演出与海报风格均为虚构，用于说明三轴怎么各落各的段。

## 示例：2D 赛璐璐角色 × 战斗招式 × 电影一页海报式

### 输入

- 角色参考图：`图1：形 —— 保留方圆脸 / 短眉 / 琥珀色圆瞳`；`图2：服装 —— 保留立领短外套 + 单侧肩甲`
- 设定：名字 **Ember**，称号 **the Ash Warden**，能力 = 火力，主场场景 = 火山灰废墟，标志物 = 腰间一枚裂开的铜哨
- 演出：skill 推荐 `combat-moves`（能力=火力、配深色戏剧光）与 `hero-motion`，用户选 **战斗招式**
- 海报风格：用户没指定 → 给候选，用户选 **电影一页海报式（`cinematic-onesheet`）**
- 文字层：用户要角色名 + 称号，语言英文

### ① 角色锁定（两块，逐字复用）

复杂度判定：**第 3 档（复杂）**——多层服装 + 单侧肩甲，含滚边与裂纹细节，无武器 → 锚点写到**逐件结构层**。

```
## 角色锚点卡 · Ember

### A 角色成像锁定
- 媒介：二维数字绘画
- 笔触与线稿：干净闭合的黑轮廓线，线宽统一，不抖动
- 上色方式：赛璐璐平涂分色，硬边单层阴影，一道窄高光
- 光照逻辑：主光来自右上，硬边二分，无渐变
- 材质质感：色块 + 高光位置暗示，无照片级纹理

### B 视觉锚点
1. 面容：方圆脸，下颌线柔和；短平眉、眉尾略下压；琥珀色圆瞳、双眼皮窄；肤色偏暖小麦色；左颊一道三厘米旧疤自颧骨斜向下。
2. 头面部附属：齐耳短黑发，三七分（分缝在左）、发梢微翘、额前两缕碎发；无耳饰、无尾。
3. 体型与身体：约七头身，肩窄腰细；双腿裸露、膝下无护具；赤足穿半旧短靴（鞋头磨白）。
4. 服装（逐件）：
   - 立领短外套：深炭灰哑光布，前襟双排铜扣各三枚；立领高约三指，领口内侧一道琥珀橙滚边。
   - 单侧肩甲：仅右肩，铜色硬质、三段式分片，以两条皮带自右肩斜扣至左腰。
   - 宽皮带：深褐皮革，宽约一掌，正中一枚方形铜扣。
5. 武器 / 装备：无手持武器；腰间右侧挂一枚裂开的铜哨（哨身两道裂纹、铜绿明显）。
6. 配色：主色深炭灰（外套 + 靴）；辅色铜褐（肩甲 + 皮带 + 铜扣）；强调琥珀橙**只出现在**瞳、领口滚边、铜哨三处。
7. 标志物：腰间裂开的铜哨——它同时是唯一发声物件与唯一"破损"物件，是"已用过一次"的叙事证据。
```

### ② 演出（查库 → 命中 `combat-moves`）

命中判据：姿态（发力瞬间、拧腰转胯）、手部（握持出招）、情境（交手中）、机位（低角度仰拍）、序列（起手→连击→收招→定格）——五项吻合。

单姿态取 **命中**；机位取 **低角度仰拍**。

### ③ 海报风格（查库 → 命中 `cinematic-onesheet`）

命中判据：版式（三段式：标题块 / 主视觉 / billing block）、字体（全大写收紧字距）、图文关系（标题压暗部）、色彩（深色基调 + 单一强调）、装饰（极少）——五项吻合。

### ④ 主视觉海报 prompt（编译后）

```
电影一页海报式角色主视觉海报，3:4。

## 输入
角色 Ember / 称号 the Ash Warden / 能力：火力 / 场景：火山灰废墟 / 画幅 3:4 / 语言 English。

## 角色锁定（最高优先级，不得被下方任何段改写）
（角色锚点卡全文，逐字）
角色的成像媒介、笔触、上色、光照逻辑、材质与配色，全部以上文为准。
背景可按下方海报风格给渐变氛围，但**角色本体的上色仍为赛璐璐平涂分色，不得渐变**。

## 演出（中优先级）
（战斗招式原子全文，逐字）
单姿态：命中。机位：低角度仰拍（增强压迫），斜角带一点失衡感。
发力链：脚 → 腰 → 肩 → 手，方向一致；衣摆与武器尾迹带出残影。
表情冷峻，视线锁定对手，不喊叫。

## 海报风格应用
纵向三段：标题块（上 15%）/ 角色主视觉（中段）/ billing block（底部 15%）；
主标题全大写、字距收紧，压在暗部；深青基调 + 单一琥珀橙强调色；
背景允许渐变营造电影感；billing block 为密集小字；装饰极少。

## 构图
角色占画面高约 70%，居中偏左；低角度仰拍；背景为火山灰废墟的剪影与扬尘；
标题 "EMBER" 置于标题块，称号 "THE ASH WARDEN" 在其下；billing block 贴底。
（占比与位置归海报风格；角度归演出——两者不越界。）

## 图文关系
标题压在暗部，可叠在角色下缘，但不遮脸与铜哨。

## 字体
全英；高对比窄体无衬线，全大写，字距收紧；主字 600、billing 小字 400；
颜色取暖白；对比 ≥4.5:1；字母精确渲染。

## 负向约束
无网格线、无边框、无角标、无中文、无水印、无签名、无 logo、无 nameplate、无外文品牌名水印；
不得改变角色的成像媒介与角色配色；禁泛词（帅气 / 华丽 / 震撼 / 压迫感）。

## 终稿标准
只出一张；不出解释 / 备选 / 拼图。
画面干净通透、避免过度锐化、噪点、伪细节。
```

### ⑤ 人物设定图 prompt（方向 `sheet`，改动段）

```
## 版式分区
按演出序列逻辑排四格：起手 → 连击（命中）→ 收招 → 签名定格。
主位给「命中」的全身姿态（占画面最大）；其余格给起手 / 收招 / 定格。
分区之间用留白与光区分，不画网格线与边框。
所有格子的角色成像与配色完全一致，只允许姿态 / 视角 / 表情不同。

## 字体
只保留角色名 "EMBER"（全英小字，右下角留白）。
```

其余段照主视觉同款，角色锚点卡与演出原子逐字一致。

## 反例对照

| 反例 | 为什么错 | 改法 |
|---|---|---|
| 锚点只写到**类别层**（如"黑色战术装束 + 分片护甲 + 束带"） | 模型会自己编分片与束带走向，成图"像但不是" | 写到**结构层**：几段分片、束带从哪到哪、细节线在哪个位置 |
| 简单角色硬写结构层（"大面积纯色短袍"非要拆成几片几段） | 写不出来，还会稀释别的段 | **按复杂度选深度**：简档写"类别 + 主色"就够 |
| 把「真人 / 3D / 2D」放进画风库 | 那是角色成像，参考图已决定；放库里＝职责重复、与 i2i 打架 | 成像进**角色锚点卡**的成像锁定 |
| 把姿态 / 动作语言写进海报风格原子 | 那是演出轴的事，会与另一套来源打架 | 挪进 `staging/{id}/` |
| 在海报风格里写"低角度仰拍" | 角度归演出，占比才归海报风格 | 角度写进演出原子 |
| 演出原子要求全身大张力，海报风格却要求角色占 40% | 两者越界了 | 演出定姿态、海报风格定占比；冲突时缩小占比，不改姿态 |
| 用 `hero-motion` 配 `minimal-editorial` | 两个原子 `conflicts_with` 互斥（动 vs 静） | 换配对，或明确说明让步了哪一条 |
| "参考图1是角色" | 没说取它的什么 | 写清用途分工：形 / 色 / 服装 / 道具 |
| "锐利的眼神，疲惫的气质" | 情绪词模型不画 | 拆成几何量：眉骨高 + 眼神冷 + 不笑 |
| 泛词"帅气 / 华丽 / 震撼" | 演出原子明令禁止 | 换写成具体动作 + 重心 + 机位 |
| 文字写 "Ember 灰烬守望者" | 画面文字必须全英 | 只写 "EMBER / THE ASH WARDEN" |
