# 人物设定图骨架（方向 `sheet`）

**1 张，3:4。主位 + 多视角（正 / 侧 / 背）+ 表情。排版样式随所选海报风格原子变，不是固定版式。**

## 与主视觉的分工

| | 主视觉海报（`keyvisual`） | 人物设定图（`sheet`） |
|---|---|---|
| 视觉中心 | 1 个 | 1 个主位 + N 个辅位 |
| 视角 | 单一机位 | 多视角（正 / 侧 / 背） |
| 姿态 | 单姿态 | 主位 1 个 + 辅位若干 |
| 表情 | 单一情绪 | 主位 1 个 + 表情特写 |
| 文字 | 角色名 + 称号 | 角色名 + 可选视角 / 表情标签 |
| 用途 | 一张打出去 | 一次看全这个角色 |

## 版式由海报风格原子决定

分区方式照所选海报风格原子的 `sheet_shape_adaptation` 走。**不同风格给出不同的设定图排版**（如 `hud-keyart` 用档案条 + 四角 HUD 分格；`cinematic-onesheet` 用标题块 + 多视角区 + billing block 当标注位）。

不变的三条：

- **一张画布，分区排布**：主位给最大最完整的一个全身姿态，其余位给正 / 侧 / 背视角、表情特写、标志物特写。
- **不画等宽网格线与装饰边框**——用留白、光、或该原子自带的引导线（HUD 细线 / 封面线 / billing block）分区。
- **允许极简标注**：视角 / 表情标签可用该原子自己的文字系统承载（如封面线、billing block、HUD 小字），**仍受「画面文字全英」约束**。

**同一成像贯穿全图**（角色锁定）：不做成"拼贴的不同成像 / 不同画风"。多格之间只允许构图与姿态不同，**成像媒介、笔触、上色、光照逻辑、材质与配色必须完全一致**。

## 姿态序列由演出原子决定

多格怎么排，照所选演出原子的**序列逻辑**段走（战斗招式 = 起手 → 连击 → 收招 → 签名定格；日杂动作 = 生活四格切片；时尚摆拍 = 走位 → 回眸 → 坐姿 → 面部特写）。

**演出只换姿态与视角，不换成像**。

## 必含

1. 一个主位全身姿态（正面或 3/4 侧），占画面最大
2. ≥1 个异视角（侧面或背面）
3. ≥2 个表情特写
4. 标志物特写（第 5 锚点）
5. 角色名（全英，小字，不抢戏）

## 数量约束

- 位格 3–5 个（含主位），表情 2–4 个，视角 2–3 个。
- 宁可少而清楚，不要塞满。**判据：每一位删掉后，观众是否损失信息？** 不损失 → 删。
- 若所选海报风格原子的 `sheet_shape_adaptation` 写明了上限、而当前排法超出（如 `minimal-editorial`），降级为「主位 + 2 视角」的极简版，并告知用户。

## prompt 编译骨架

与主视觉同一骨架，只改两段：

```
## 构图 → 版式分区
主位全身姿态（占画面最大）/ 异视角位 / 表情位 / 标志物位
分区方式照 sheet_shape_adaptation；分区之间用留白、光或该原子自带的引导线，不画等宽网格线与装饰边框
→ 明确写一句：所有位格的成像与配色完全一致，只允许姿态 / 视角 / 表情不同
→ 若该原子装不下多格，写明降级为「主位 + 2 视角」

## 字体 → 按该原子的文字系统
角色名为主；视角 / 表情标签用该原子自己的小字系统承载，全英，不抢戏
```

其余段（角色锁定 / 演出 / 海报风格应用 / 图文关系 / 负向 / 终稿标准）照 `skeleton-keyvisual.md` 同款。
**画幅同样固定 3:4**；输出档位见 `config.md`。
**prompt 长度预算与压缩顺序同 `skeleton-keyvisual.md`（正文 ≤ 800 字）**——设定图格数多，最容易超，先按"换写法"压。

## 自检（6 条）

- [ ] 是不是 3:4、一位主位 + 多视角 + 表情？
- [ ] **多格顺序是否照演出原子的「序列逻辑」段走？**
- [ ] 版式是否照该原子的 `sheet_shape_adaptation` 走（不是套固定模板）？
- [ ] 有没有画出等宽网格线 / 装饰边框 / 角标？（有即返工）
- [ ] **各格的成像与配色是否完全一致、且与锚点卡一字不差？**（不一致 → 返工）
- [ ] 文字是否全英、标注是否用该原子自己的文字系统？
