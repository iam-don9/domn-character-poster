# 主视觉海报骨架（方向 `keyvisual`）

**1 张，3:4，单姿态主打。**

## 骨架由海报风格原子决定（不是由角色成像决定）

构图 / 版式 / 字体 / 图文关系**照所选海报风格原子的 `keyvisual_shape_adaptation` 走**，不套固定模板。

角色**怎么成像**（真人 / 3D / 2D / 笔触 / 材质）**不在这里定**——那是 `anchor-card.md` 的成像锁定，且**优先级更高**。

| 谁 | 管什么 |
|---|---|
| 海报风格原子 | 角色在画面里占多大 / 标题在哪 / 字体气质 / 留白与分区 / 背景色彩氛围 / 装饰 |
| 角色锚点卡 | 角色的成像与长相（**不得被海报风格改写**） |

## 必含六件

1. **主体**：单角色，单姿态（一个动作 / 情绪，不摊开多个）
2. **环境 / 背景**：与角色设定一致的主场场景，或按海报风格给的背景方案
3. **光**：只写物理事实——色温 + 方向 + 照到哪
4. **构图**：角色占画面比例 + 视线方向 + 留白位置（按海报风格原子）
5. **文字层**：角色名 / 称号（全英），位置与字体按海报风格原子 + `typography.md`
6. **点缀**：按海报风格原子的装饰配额；面积不超其规定上限，不得污染主体

## prompt 编译骨架（照 blueprint）

```
{海报风格名} 角色主视觉海报，3:4。

## 输入
角色 / 称号 / 设定摘要 / 画幅 3:4 / 语言 English
→ **画幅固定 3:4**；输出档位见 `config.md`（当前 `1K` = 768×1024）

## 角色锁定（最高优先级，不得被下方任何段改写）
角色锚点卡全文（成像锁定 + 七项视觉锚点，逐字）
→ 明确写一句：角色的成像媒介、笔触、上色、光照逻辑、材质与配色，全部以上文为准。

## 演出（中优先级）
演出原子全文（姿态与肢体语言 / 手部动作 / 表情与视线 / 情境 / 机位角度，逐字）
→ 单姿态取「单姿态」段里的 1 个；**机位只写角度，不写版面占比**（占比归下方海报风格）。

## 海报风格应用
逐条落进画面：style_anchors / keyvisual_shape_adaptation / must_preserve / avoid_when_applying_to_keyvisual
（不许只挂风格名——每条都要说它体现在画面的哪一处）
（只管版式 / 字体 / 图文关系 / 背景色彩氛围 / 装饰）

## 构图
主体 / 背景 / 光 / 构图 / 文字位 / 装饰

## 图文关系
标题如何与主体融合（不是贴上去的）

## 字体
全英；按海报风格原子 + typography.md

## 负向约束
通用 slop 禁项 + avoid_when_applying_to_keyvisual
+ 「不得改变角色的成像媒介与角色配色」

## 终稿标准
只出一张；不出解释 / 备选 / 拼图
```

## 长度预算与压缩顺序（硬约束）

**prompt 正文 ≤ 800 字（约 1.5 KB）**——见 `SKILL.md` 硬规则第 14 条。超了按这个顺序压：

1. **换写法**：完整句 → 顿号串联短语（`巨大薮猫耳（耳背黑、白色眼斑、黑耳尖）；浅金碎发`）。**这一步通常就能省掉一半字数。**
2. **砍锚点**：删"模型不会自己编"的条目（判据见 `anchor-card.md`）。
3. **去重**：同一信息只写一次——角色配色与海报配色不许各写一遍。

**不许为短而删**：角色锚点 / 张力六条 / 文字全英 / 降噪后缀。

> 实测：4.4 KB 的 prompt → 上游生成过久 → 502 ×3；砍到 1 KB → 立刻成功，**且成图质量更好**。

## 自检（7 条）

- [ ] 是不是 3:4、单姿态？
- [ ] **姿态是否来自演出原子的「单姿态」段，机位角度是否照演出原子写？**
- [ ] 海报风格锚点有没有真的落在画面上（不是只写了名字）？
- [ ] **角色的成像与配色，是否与锚点卡一字不差？**（被海报风格改掉 → 返工）
- [ ] 角色锚点卡是不是逐字复用？
- [ ] **prompt 正文是否 ≤ 800 字**？（超了 → 按上面的压缩顺序压，不许删关键锚点）
- [ ] **锚点是否写到了结构层**（分片 / 段数 / 走向 / 数量 / 比例）？只写到类别层 → 返工。
- [ ] 文字层是不是全英、位置不遮主体脸与标志物？
