# 角色锚点卡（成像锁定 + 视觉锚点）

一致性靠 **参考图 i2i + 锚点卡文字** 双锁。锚点卡就是那把"文字锁"。

**卡分两块：** A 角色成像锁定（防海报风格污染），B 视觉锚点（防换脸 / 换装 / 换武器）。

> ⚠️ **本卡是「复刻锁」，不是「最小识别点」。**
> 宣传物料要把参考图的**具体造型**复刻出来，所以凡参考图里**有明确造型**的部件，都要写到**与该角色复杂度相称的深度**——不写到位，模型就自由发挥，成图会"像但不是"。

---

## 先定锚点深度（按角色复杂度选）

**深度不是固定的。** 先看参考图判复杂度，再决定锚点写到哪一层。

| 档 | 判据（看参考图） | 锚点写到 |
|---|---|---|
| **1 简** | 造型元素 ≤5 个、大面积纯色、无装备或只 1 件 | **类别 + 主色**（"深灰立领外套，无纹样"） |
| **2 中** | 有 1–2 个结构件（护甲 / 披肩 / 配饰） | **件级 + 关键结构**（分几片、束带走向） |
| **3 复杂** | 多层服装 + ≥2 件装备，或带非人特征（兽耳 / 尾 / 足）或纹样 | **逐件结构层**（分片 / 段数 / 走向 / 数量 / 比例） |
| **4 极复杂** | 机械 / 义体 / 多层甲 + 多武器 + 复杂纹样 | 逐件结构层 **+ 连接关系与相对比例**；必要时逐件编号 |

**怎么判**：数参考图里"有明确造型、且模型可能自己编"的部件数——**≥3 件就至少第 3 档**。

**两条纪律**：

- **低复杂度不要硬写结构层**——写不出来，还会稀释别的段。
- **高复杂度不许省**——省了就等着模型自由发挥。

> 本 skill 的深度档与资产库的道具「复杂度四档」同一套口径。

---

## A · 角色成像锁定

**为什么要有这块**：海报风格原子自带一套视觉语言（版式、字体、色彩氛围）。若不加锁，模型会让**角色本体**去迁就海报风格，把原本的真人画风渲染成插画、或把 2D 角色渲染成 3D。**成像锁定就是那道防线。**

从参考图逐项读出，五项全部写死：

| 维度 | 读什么 | 例 |
|---|---|---|
| 媒介 | 摄影 / 3D 渲染 / 数字绘画 / 手绘线稿 / 版画 | 数字绘画 |
| 笔触与线稿 | 有无轮廓线 / 线宽 / 线条质感 | 干净闭合黑线，线宽统一 |
| 上色方式 | 平涂 / 厚涂 / 渐变 / 赛璐璐分色 / 水彩 | 赛璐璐平涂分色 |
| 光照逻辑 | 光源方向 / 硬软 / 冷暖 / 是否戏剧化 | 硬边单层阴影，主光来自右上 |
| 材质质感 | 皮肤 / 布料 / 金属的表达方式 | 平涂 + 窄高光，无照片级纹理 |

**判据**：把海报风格原子换掉，这五项必须**一个字都不变**。

## B · 视觉锚点（七项，全部写到结构层）

| # | 锚点 | 必写（结构层） | 仍不写（噪声） |
|---|---|---|---|
| 1 | 面容 | 脸型 / 骨相 / 眉形 / 眼型 / 瞳色 / 肤色 + **标志性纹路**（疤 / 泪痕 / 面纹） | 毛孔、细纹、毛细血管 |
| 2 | 头面部附属 | 发型（**刘海分缝 / 长度 / 发色分层**）、耳或角（**形 / 长 / 姿态 / 颜色分段**）、尾 | 单根发丝走向 |
| 3 | 体型与身体 | 头身比、裸露部位、四肢形态、**足部形态**（兽足 / 靴 / 赤足） | 肌肉纤维、血管 |
| 4 | 服装 | **逐件写**：件名 + 结构（**分片 / 段数 / 走向**）+ 材质（蓬松毛皮 / 哑光布 / 硬甲）+ 穿法 + 细节线（**颜色 + 位置**） | 面料纤维、织法、水洗标 |
| 5 | 武器 / 装备 | 结构（**分片 / 关节 / 连接方式**）+ 形制（**刃的数量、长度比例、朝向**）+ 材质与配色 | 螺丝纹路、磨损微痕 |
| 6 | 配色 | 主 / 辅 / 强调 + **各自出现在哪些件上**（映射，不是清单） | 每件小物的色号 |
| 7 | 标志物 | 1 个最强识别点，写清**为什么**它是记忆点 | 一堆零碎配饰 |

### 四条判据（按顺序用）

1. **先定深度** — 按上面的复杂度档，定这个角色写到哪一层。
2. **下限** — 在所选深度内，凡参考图里**有明确造型**的部件（护甲分片、束带走向、拳套结构、兽足、耳形）都要写到该层。
3. **一句话判据** — **「这条删掉，模型会不会自己编一个？」会 → 必须写。**
4. **上限** — 微细节仍不写（不进画面、也不构成识别点）。

> 另：**取景判据**仍然有效——角色卡取到胸口，就不写腰带与鞋。

## 写法

- **用顿号串联的短语，不用完整句。** 锚点卡最终要整段进 prompt，而通道对 prompt 长度敏感（见下「长度预算」）——**写法本身就要密**。
  - ✅ `巨大薮猫耳（耳背黑、耳中有白色眼斑、耳尖黑）；浅金碎发；橙金竖瞳、眼周黑眼线`
  - ❌ `角色拥有一对巨大的薮猫耳朵，耳朵背面是黑色的，耳朵中间有一块白色的眼斑，耳尖也是黑色的……`
- 两块都写成**固定措辞**，所有图的 prompt **逐字复用**——不改写、不省略、不换词。
- 结构层描述要**可核对**：写"三段式分片护甲、束带自左肩斜向右腰"这类几何事实，**不写"精致""复杂"**。
- 面容锚点要含"可对比的几何量"（如"下颌线锐利""眉骨高"），不要情绪词（"锐利"≠"凶"）。
- 写静态体征，不写情绪 / 姿态词（"憔悴"要写成"眼窝深陷 + 眼下青黑 + 唇色发白"）。
- **配色锚点只管角色自己**；背景 / 标题 / 装饰的颜色归海报风格原子，别混进来。

### 长度预算（硬约束）

锚点卡是 prompt 里最长的一块，**整卡控制在 ~400 字以内**——复杂角色也不例外。

- 超了**先砍"模型不会编"的条目**（判据见上），**不是**把句子压到看不懂。
- 通道约束：prompt 越长 → 上游生成越久 → 撞网关超时 → 502（实测 4.4 KB 连败 3 次，1 KB 立刻成功）。

## 与另两轴的关系

本卡管**角色长什么样、怎么成像**，优先级最高。「角色在做什么」归 `staging/`，「海报怎么排」归 `styles/`——三轴分工与优先级见 `SKILL.md` 的「三条互不越界的轴」。

## 卡的样子（结构）

```markdown
## 角色锚点卡 · {角色名}

### A 角色成像锁定
- 媒介：…
- 笔触与线稿：…
- 上色方式：…
- 光照逻辑：…
- 材质质感：…

### B 视觉锚点
1. 面容：…
2. 头面部附属：…
3. 体型与身体：…
4. 服装（逐件）：
   - 件 1：结构 / 材质 / 穿法 / 细节线
   - 件 2：…
5. 武器 / 装备（逐件）：结构 / 形制 / 材质与配色
6. 配色：主 …（出现在 …）；辅 …（出现在 …）；强调 …（只出现在 …）
7. 标志物：…（为什么是记忆点）

（以下整段逐字进所有图的 prompt，且不得被海报风格原子改写）
```
