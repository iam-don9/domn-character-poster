# 画面文字（全英）

## 铁律：画面文字全英

- 角色名 / 称号 / 任何可见文字 → **英文**。
- 中文只在**对话里**，不进画面。
- 不出现水印 / 账号名 / 署名 / 品牌 nameplate。

## 先问后做

文字层**不预设**。先问用户：

1. 要不要文字？
2. 要哪几层（名 / 称号 / 一行设定）？
3. 语言？（建议：全英）

## 文字档位（先定档，再定层）

问用户时**先定这一档**——它决定画面有没有标题类文字：

| 档位 | 含什么 | 适合 |
|---|---|---|
| **A 全文字** | 标题 / 角色名 / 称号 / 设定标签 + 装饰文字 | 默认；海报风格原子的识别件靠文字成立的场景 |
| **B 仅装饰文字** | 不要标题、角色名、标语；只留装饰性字符（版本号 / 编号 / bar code / 刻度） | 想纯画面、但接受 HUD 质感 |
| **C 无文字** | 画面零文字 | 纯画面 key visual |

**⚠️ 与原子冲突时必须明说**：库里的海报风格原子**全部依赖文字成立**（`hud-keyart` 靠巨型 3D 标语 + 副标 + 角色档案条；`cinematic-onesheet` 靠标题块 + billing block；`magazine-cover` 靠刊名 + 封面线；`minimal-editorial` 靠一个衬线主标题）。

判 **B / C** 时：**先告知用户会砍掉哪些识别件，再给替代方案**（换风格 / 降级 / 现生成一档无文字原子），**不许硬凑**。

## 三层文字（按需）

| 层 | 内容 | 字级 | 位置 |
|---|---|---|---|
| A | 角色名 | 最大 | 视觉重心附近的留白 |
| B | 称号 / epithet | 中 | A 下方或侧边 |
| C | 一行设定 | 最小 | 边角 |

- 主视觉海报默认给 A + B；人物设定图只给 A（另可按海报风格原子的文字系统加视角 / 表情标签）。
- 不堆字体；最多两个层级字体（一个主、一个辅）。

## 字体规定（严格，七项）

**字族由所选海报风格原子决定**（那是排版风格的一部分），不是由角色成像决定。

| 项 | 规定 |
|---|---|
| 字族 | **按海报风格原子的「字体」段**；该段没写死时才按调性补：编辑克制 → 高对比衬线；现代几何 → 无衬线；档案 / 手记 → 等宽或手写 |
| 字重 | 主 ≤700；辅 400 |
| 层级 | ≤3 层，相邻字级差 ≥1.5 倍 |
| 位置 | 按海报风格原子的版式；且不遮主体脸与标志物 |
| 字号 | 主字占画面宽度 20%–35%（主视觉） |
| 颜色 | 从**海报风格原子**的标题色取，与背景对比 ≥ 4.5:1（**不用角色配色**） |
| 渲染 | 每个字母精确渲染，不许错拼 / 裁切 / 变形 |

**判据**：只写"字体随画面"＝交给模型自由发挥，每张字体都不一样。必须给全七项。

## 负向

无中文、无水印、无签名、无 logo、无 nameplate、无外文品牌名水印、无随机英文说明文字。
**禁用 3D 立体字**——最土的文字形式。文字的立体感只能来自**它所在的平面**（墙面 / 地面 / 倾斜板等的厚度与透视），不能来自字本身被挤出立体。
