# 演出原子生成

把一套「角色在做什么」转成可复用的结构化原子（`STAGE.md` + `META.md`）。

## 只管三件事

**姿态与肢体语言 / 情境 / 机位角度。**

不许写：角色成像与长相（归 `anchor-card.md`）、海报版面与字体（归 `styles/`）。
机位**只写角度**（仰 / 俯 / 平、正 / 侧 / 背、透视强度），**不写版面占比**——占比归海报风格。

## 素材来源（三条）

1. **用户提供的提示词 / 参考图** → 直接提词。
2. **`domn-film-action-director/references/05-arsenal.md`**（视频打戏素材）→ ⚠️ **必须剥离时间维度**：
   - **取**：高强度动词库（按载体分 7 类）、质感强化词、泛词黑名单、"取类型不取成品招"原则。
   - **丢**：回合节奏、慢拍库、每拍 0.2–0.5s、连续因果、密度标准。
   - **理由**：那些是**视频**逻辑（要连续可执行）。静态海报只要**签名帧**。
3. **huashu 方法生成**（无现成素材时）：真名锚点替代形容词；结构性 vs 气质性二分（气质性的必须补结构化描述）。

## 读素材六维

逐项写"看到了什么"，不写"感觉像什么"：

| 维度 | 读什么 |
|---|---|
| 姿态与肢体语言 | 重心落点 / 张力方向 / 对称性 / 四肢开合 |
| 手部动作 | 手在做什么 |
| 表情与视线 | 情绪 + 看向哪 |
| 情境 | 场景类型与正在发生的事 |
| 机位与角度 | 仰 / 俯 / 平、正 / 侧 / 背、透视强度 |
| 序列逻辑 | 多姿态怎么排 |

## 四条硬约束

1. **原子只写演出**——不写角色长相、不写海报版面。
2. **每档必须给两套**：「单姿态」（主视觉海报用）+「序列逻辑」（人物设定图用）。
3. **禁泛词**——帅气 / 炫酷 / 震撼 / 强烈的动感 / 压迫感，一律换写成**具体动作 + 重心 + 机位**。
4. **战斗类取"类型与强度"，不取"成品招"**——招式必须结合当前角色现造。
5. **不贴单一气质标签**——禁止把一档演出写成单一气质（如"摆拍＝静"）。每档都要说明它在**低张力与高张力两端**各长什么样，并让执行时**先问"这个角色配哪一端"**，不许默认选安全的那端。
