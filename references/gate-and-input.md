# 门槛与输入

## 硬门槛：必须有参考图

**没有用户提供的角色参考图 → 停下，要求提供。** 不自动 t2i，不用文字设定硬编一个角色。

判据：拿不到图，就不进入任何后续步骤。

## 输入三件

| # | 输入 | 必填 | 说明 |
|---|---|---|---|
| 1 | 角色参考图 | 是 | ≥1 张；多张时按用途分工标注 |
| 2 | 角色设定信息 | 是 | 名字 / 称号 / 性格 / 能力 / 标志物 / 主场场景 |
| 3 | 文字层意图 | 是 | **先问用户**；建议口径为全英 |

## 多张参考图：按用途分工标注

每张都要写清「**用它的什么**」，不许只写"参考这张"。

| 用途 | 取什么 |
|---|---|
| 形 | 脸型 / 五官 / 骨相 / 比例 |
| 色 | 配色 / 肤色 / 主色调 |
| 服装 | 服装结构 / 材质 / 纹样 |
| 道具 | 标志物 / 武器 / 配饰 |

标注格式：`图N：<用途> —— 保留 <具体部位/属性>`。

### 同时必须写清「不继承什么」

参考图里**素材本身的版式与瑕疵会被模型一起继承**。逐条否掉：

| 常见继承物 | 要否掉 |
|---|---|
| 三视图 / 多视图分格 | 只取角色形象，不继承分格与拼贴 |
| 遮挡块（贴纸 / 色块 / 打码） | 不继承任何遮挡 |
| 棚拍白底 / 灰底 | 不继承背景 |
| 参考图自带的文字、水印、编号 | 不继承 |

**判据**：只要参考图里有一件"我们不想在成品里看到"的东西，就必须点名否掉——**不写，模型大概率照抄**。
（实测：三视图角色素材若不否掉，成图会保留分格，并把正面视图上的黑色遮挡圆块一起画进去。）

## 参考图只管一件事

参考图只决定**角色成像与长相**。演出与海报风格**都不从参考图推断**——它们的来源与链路见 `library-rules.md`。

## 文字层：先问后建议

**不预设**。先问用户：画面要不要角色名 / 称号 / 设定文字、用什么语言。

- 建议口径（默认）：**全英**。
- 用户明确要中文 → 按用户。
- 用户说不要文字 → 走纯画面。
- 不许替用户决定。

## 缺信息时怎么办

| 缺什么 | 动作 |
|---|---|
| 缺参考图 | **停**（硬门槛），要求提供 |
| 缺设定信息 | 可只靠参考图推进，但主动问一句"要不要补名字 / 称号" |
| 缺文字层意图 | 问，不许替用户决定 |
| 参考图质量差 / 看不清角色 | 说明哪一处不可辨，请用户补图或确认推定 |

## 名词必须拆成可画元素

**所有"物种 / 职业 / 风格名词"都是漏题高发区**——模型不会自动把名词映射成画面。

反例：写「猫头鹰与猫科混血」，模型只会画出猫科 + 一个鸟喙嘴套。

| 名词 | 拆成的可画元素 |
|---|---|
| 猫头鹰 | 鸮面盘（心形面纹）+ 耳羽簇（头顶尖立羽毛，**不是猫耳**）+ 猛禽金圆瞳 + 钩喙 + 翅膜披风 |
| 钳工 | 厚帆布袖套 + 油污黑指甲 + 扳手手型 |
| 赛博朋克 | 霓虹角点 + 雨夜 + 义体光带 |

**判据**：写角色 prompt 时，任何名词都立刻拆成视觉画得出的元素。
