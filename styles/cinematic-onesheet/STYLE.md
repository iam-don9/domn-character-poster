# 电影一页海报式

## 视觉风格原子

一张经典 one-sheet 电影海报：角色主视觉居中或偏置，上方或下方一块大标题，底部一条密集小字的 billing block，深色基调 + 单一强调色，信息层级像电影宣传物料。

## 输入变量

- 角色：{{角色名}}
- 角色设定摘要：{{...}}
- 画幅比例：3:4
- 语言：English
- 点缀：{{不使用 / 一条分隔细线}}

## 风格基因

### 版式

- 纵向三段：**标题块 / 角色主视觉 / billing block**（顺序可上下互换，但三段必须齐全）。
- 标题块与 billing block 各占画面高约 12%–18%；主视觉占中段。
- 信息层级：主标题 > 角色 > billing block。

### 构图与分区

- 角色主视觉居中或按三分线偏置，环境背景托底。
- 主视觉落点唯一；不把角色切成多个分区。
- 标题块与 billing block 之间可有一条细横线分隔。

### 字体

- 主标题：高对比衬线或窄体无衬线，**全大写**，字距收紧。
- billing block：小号窄体，多行密集排列（模拟演职员表），字级明显小于主标题。
- 最多两个层级字体。

### 图文关系

- 标题压在暗部或留白上，可叠在角色下缘，但**不遮脸与标志物**。
- billing block 贴底边，两侧留安全边距。

### 色彩系统

- 背景：深色基调（深青 / 深褐 / 近黑）。
- 强调色：最多一种（如朱红 / 琥珀 / 冷青），只出现在标题或一处光。
- 允许背景渐变（电影感），但不做霓虹与发光。

### 装饰元素

- 极少。允许一条细横线、一处极小的时间/版本标记。
- 装饰总面积 ≤3%。

## 生成前检查

- 三段（标题 / 主视觉 / billing block）是否齐全？
- 主标题是否全大写、字距收紧？
- 强调色是否只有一种？
- billing block 是否是密集小字、不抢戏？
- 是否没有多强调色、没有杂志封面线？

## 风格特有禁用项

- 不要扁平插画缩略图感、不要商业模板感。
- 不要杂志封面线、期号、条码位。
- 不要多种强调色。
- 不要霓虹、赛博蓝光、发光金属。
