# 杂志封面式

## 视觉风格原子

一张杂志封面：角色半身或全身居中占画面主体，顶部一块强个性刊名大字，四周分布若干封面线（cover lines）与期号信息，整体是"刊物"而非"单张画"。

## 输入变量

- 角色：{{角色名}}
- 角色设定摘要：{{...}}
- 画幅比例：3:4
- 语言：English
- 点缀：{{不使用 / 期号条}}

## 风格基因

### 版式

- 顶部刊名区占画面高约 18%–25%，横向占宽 60% 以上。
- 角色主体占中段，可越过刊名区（人物遮住部分刊名是封面惯例）。
- 封面线分布：左右两侧各 1–3 条，或顶部刊名下方 1 条。
- 期号 / 日期 / 条码位放边角。

### 构图与分区

- 角色居中或略偏，视线可看向刊名区或直视读者。
- 刊名区 / 主体区 / 信息区三层，层级清楚。
- 封面线围绕主体但不侵入脸部。

### 字体

- 刊名：强个性字（粗衬线或定制感无衬线），可略作字距调整。
- 封面线：小号无衬线，字级明显小于刊名。
- 期号 / 日期：最小号，等宽或窄体。

### 图文关系

- 刊名可被角色头部遮挡一部分（封面惯例），但**刊名主体仍可读**。
- 封面线**不遮脸、不遮标志物**。

### 色彩系统

- 背景：纯色、摄影或与角色对比的色块。
- 强调色：最多一种，用于刊名或一条封面线。
- 高饱和或低饱和均可，但整张统一。

### 装饰元素

- 期号条、日期、条码位、一条细分隔线。
- 装饰总面积 ≤5%。

## 生成前检查

- 刊名区是否够大、够醒目？
- 封面线是否 1–3 条、不遮脸？
- 期号 / 日期 / 条码位是否在边角？
- 是否**没有出现任何真实刊名 / 报头**？
- 强调色是否只有一种？

## 风格特有禁用项

- **不要真实杂志 / 报纸名、不要报头 nameplate、不要外文品牌水印**（最高优先禁令）。
- 不要做成一张普通插画（必须有刊名区 + 封面线，才成立）。
- 不要超过 3 条封面线、不要让封面线遮脸。
- 不要多种强调色、不要霓虹发光。
