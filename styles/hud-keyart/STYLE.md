# HUD 高能海报

## 视觉风格原子

一张高能量现代动作 / 游戏角色 key art：动态悬停的角色主体 + **2D 涂鸦标语（画在有 3D 立体感的平面载体上）** + 四角 HUD 装饰 + 角色档案条，暗调高饱和、冷暖对撞，构图有张力，像电竞赛事级别的角色宣传物料。

> 🚫 **核心铁律：所有文字都是 2D 涂鸦，画在一个有 3D 立体感的块状平面上。**
> 立体感来自**平面的厚度 / 透视 / 角度**，**不是文字本身被做成 3D 立体字**——**3D 立体字是最土的形式，禁用。**

## 张力六条（硬约束，缺一即返工）

从 9 张官方赛季海报提炼的**张力来源**。每条都配**禁用项**——不具备张力的做法一律禁止。

| # | 必须 | 🚫 禁止 |
|---|---|---|
| 1 | **一个色相统治全图**：背景、涂鸦、光、HUD 全取角色能力色的深浅与相邻色 | 深色底 + 局部点缀色；同色系平铺无对撞；整体偏灰 |
| 2 | **字人深度交叠**：巨型标语被人物的身体或前景物体**切断**，或人物压在标语上 | 字与人各占一块、互不侵犯；标语完整不被切；字像"贴上去的浮层" |
| 3 | **人物极端偏置**：偏到画面一角（左下 / 右下 / 左上 / 右上），或按三分线偏置 | 人物居中；中轴对称；人物占满画面中央 |
| 4 | **标语尺度到 1/2 画面**，允许**出血被画框切掉** | 标语只占 1/3 且完整；标语缩在边角当标签 |
| 5 | **强广角透视**：近大远小明显，允许手脚 / 武器适度夸张变形 | 中焦平视；棚拍式等距；透视平 |
| 6 | **背景与人物发生关系**：立柱 / 断墙 / 石阶 / 光效**参与构图**，人物与之有遮挡、投影或接触 | 背景只做剪影或雾；空景；人物悬在场景里 |

## 风格基因

### 版式

- **巨型标语是第一视觉**，占画面 1/3 以上。**字位置**：左上 / 右上 / 中央 / 居中偏上 / 垂直堆叠。
- **标语布局四选一**：斜插大块（默认）/ 垂直堆叠（4–5 字母从上到下）/ 3 行垂直（一侧堆叠多语言短句）/ 横排 + 衬线。
- **副标排版三选一**：斜插（紧邻下方）/ 居中独立 / 隐入主标（嵌进标语内部作小字）。
- **哲学引言（TAGLINE）排版三选一**：顶部双行 / 底部双行 / 斜插一行；不写引言就整段删。
- **角色档案条**为必有件，贴左下 / 左侧 / 底部：角色名 + 职业 + 地区 + 4 个圆形能力图标 + 字母按键 + 元信息。
- **元信息密度三选一**：丰富（EST 创立年 / S## 季号 / 年份 / 全息角色小图 / 4 能力）/ 中等（年份 / 4 能力）/ 极简（4 能力）。
- 信息层级：巨型标语 > 角色主体 > HUD 与档案条。

### 构图与分区

- 角色**动态姿态**，占画面高约 60%–75%。
- **人物极端偏置**：压到画面一角（左下 / 右下 / 左上 / 右上），或按三分线偏置。**禁止居中、禁止中轴对称。**
- **强广角透视**：近大远小明显；冲镜头的那只手 / 脚 / 武器可适度夸张。
- **画面焦点 = 角色与其释放的能量**，不是角色脸。
- **背景必须参与构图**：立柱 / 断墙 / 石阶 / 光效与人物发生遮挡、投影或接触关系。**禁止纯剪影背景与空景。**
- 副元素（能力延展物）位于角色周围 / 头顶 / 脚下 / 身后。
- 四角留给 HUD；主体区不切碎。

### 文字：2D 涂鸦 + 3D 平面载体（本风格的命门）

- **所有文字都是 2D 涂鸦**——喷漆 / 喷绘 / 模板喷涂 / 街头涂鸦 / 刻印。
- 文字**画在一个有 3D 立体感的平面载体上**：墙面 / 地面 / 侧立面 / 倾斜板 / 浮空厚板 / 巨型广告牌 / 石碑 / 金属板 / 倾斜路牌。
- **立体感来自平面**（厚度 / 透视 / 角度 / 与场景的空间关系），**不是字本身立体**。
- 🚫 **禁用 3D 立体字**——最土的形式。
- **次级涂鸦**：场景内其他物体表面散布**同字体风格**的次级文字——喷绘在墙、刻印在石、烧灼在木、烙在金属。
- HUD 与档案条：细无衬线 / 等宽小字，全大写。

### 图文关系

- 巨型标语与角色动态**咬合**：可被角色身体局部遮挡，但**仍可读**。
- 涂鸦文字**贴合其载体平面的透视**——墙面上的字随墙面走，地面上的字随地面倒。
- HUD 与档案条贴边、不进主体区，**不遮脸、不遮标志物**。

### 色彩系统

- **一个色相统治全图**：以角色的**能力色为主宰色相**，背景、涂鸦字、光、HUD 全取它的深浅与相邻色。
  - 🚫 禁止"深色底 + 局部点缀色"——那会整体偏灰，角色跳不出来。
- 辅色（环境对比色）只用于制造**一处对撞点**，不铺开。
- **亮部饱和度 ≥ 80%**；暗部是该色相的**暗阶**，不是灰。
- 场景色温词库只决定"**主宰色相往哪个方向偏**"（见下方词库）。

### 装饰元素（HUD）

- 四角 HUD：细线、十字定位、点阵、bar code、版本号、扫描线、HUD 中的小角色全息图标。
- 密度四档（**角色档案条不随档取消**）：

| 等级 | 填法 | 适合 |
|---|---|---|
| 极多 | 顶部扫描线 + 四角密布细线点阵 + 版本号满版 | 技术系 / 工程师 / 科幻 |
| 中等 | 细线 + 十字定位 + bar code + 角色档案条 | 大多数角色 |
| 克制 | 仅 bar code + 版本号 + 角色档案条 | 史诗系 / 元素系 / 神话 |
| 极简 | 仅角色档案条 + 收尾句 | 街头系 / 嘻哈 / 涂鸦 |

## 角色职业四分类

| 职业 | 含义 | 适合气质 |
|---|---|---|
| `DUELIST` | 决斗者 / 进攻手 | 火力压制、速度、单兵突破 |
| `CONTROLLER` | 控场者 / 视野手 | 元素控场、空间切割、烟雾 |
| `SENTINEL` | 守卫者 / 守护者 | 防御、守护、监控、信息 |
| `INITIATOR` | 启动者 / 支援 | 信息获取、探测、召唤支援 |

> 自定义职业（ASSASSIN / BERSERKER / SHAMAN / HACKER / SCIENTIST…）直接写英文单词，配合气质选字体。

## 生成前检查

- 文字是否是 **2D 涂鸦 + 3D 平面载体**（**画面里没有任何 3D 立体字**）？
- 是否有巨型标语 + 副标 + 哲学引言 + 角色档案条？
- 场景内是否有**次级涂鸦**？
- **张力六条逐条过**：① 一个色相统治全图？② 标语被人物的身体切断？③ 人物偏置到一角？④ 标语到 1/2 画面且被画框切？⑤ 强广角透视？⑥ 背景与人物有遮挡 / 投影 / 接触？
- 是否没有外文品牌名水印、没有左上角 nameplate？
- 画面文字是否全英？

## 风格特有禁用项

- 🚫 **禁用 3D 立体字**（最土的形式）——文字是 2D 涂鸦，立体感只能来自载体平面。
- 🚫 **禁用一切"安全构图"**：人物居中 / 中轴对称 / 字与人分区不交叠 / 标语完整不被切 / 背景纯剪影或空景 / 中焦平视。
- 🚫 **禁用"深色底 + 局部点缀色"**的配色（整体会偏灰，角色跳不出来）。
- 不要外文品牌名水印、不要左上角 nameplate 大字、不要真实赛事 / 游戏 Logo。
- 不要缺 HUD 或角色档案条（那是本风格的识别件）。
- 不要低饱和、不要平光、不要静态站姿摆拍。
- 不要中文标语（画面文字全英）。
