# HUD 高能海报

```yaml
id: hud-keyart
name: HUD 高能海报
input_modes: [text, image]
subjects: [person]
outputs: [keyvisual, sheet]
default_ratio: "3:4"
required_fields: [角色参考图, 角色设定]
optional_fields: [文字层, 标语, 职业定位]
source: styles/hud-keyart/STYLE.md
style_anchors:
  - 高能量现代动作 / 游戏角色 key art 的赛事级宣传视觉语言
  - 所有文字都是 2D 涂鸦，画在有 3D 立体感的平面载体上
  - 平面载体：墙面 / 地面 / 侧立面 / 倾斜板 / 浮空厚板 / 巨型广告牌 / 石碑 / 金属板 / 倾斜路牌
  - 立体感来自载体平面的厚度 / 透视 / 角度，不是文字本身立体
  - 动态悬停 / 跃起的角色主体，画面焦点是角色与其释放的能量
  - 巨型标语 + 中型副标 + 哲学引言 + 角色档案条
  - 四角 HUD 装饰：细线 / 十字定位 / 点阵 / bar code / 版本号 / 扫描线 / 全息角色小图
  - 场景内其他物体表面散布同字体风格的次级涂鸦
  - 暗部深紫或深蓝 + 亮部饱和度 ≥ 80% 的高饱和暗调配色
  - 角色档案条：角色名 + 职业 + 地区 + 4 圆形能力图标 + 字母按键 + 元信息
  - 需要真名锚点时用插画师名（Tom Whalen / Tyler Stout / Greg Rutkowski 一类），不用游戏或赛事品牌名
keyvisual_shape_adaptation:
  - 张力六条（硬约束）：① 一个色相统治全图 ② 标语被人物的身体或前景物体切断 ③ 人物极端偏置到一角 ④ 标语尺度到 1/2 画面且允许出血被切 ⑤ 强广角透视 ⑥ 背景与人物有遮挡 / 投影 / 接触
  - 巨型标语占画面 1/3–1/2，字位置左上 / 右上 / 中央 / 居中偏上 / 垂直堆叠
  - 标语布局四选一：斜插大块 / 垂直堆叠 / 3 行垂直 / 横排 + 衬线
  - 副标排版三选一：斜插 / 居中独立 / 隐入主标
  - 哲学引言排版三选一：顶部双行 / 底部双行 / 斜插一行
  - 角色占画面高约 60%–75%，动态姿态，能量为焦点；**人物偏置到一角，禁止居中**
  - 角色档案条贴左下 / 左侧 / 底部，HUD 分布四角；元信息密度三选一（丰富 / 中等 / 极简）
sheet_shape_adaptation:
  - 沿用同一暗调高饱和配色与 HUD 语言，多格只换姿态与视角
  - 巨型标语降为单行标题，中段做姿态分区
  - 分区之间用 HUD 细线与留白区分，不画网格线与边框
  - 角色档案条保留一次，不每格重复
  - HUD 密度降一档（极多 → 中等），避免多格把画面塞满
  - 上限：主位 + 3 姿态格 + 2 表情格 + 1 标志物格；再多即失去分区清晰度
must_preserve:
  - 文字是 2D 涂鸦 + 3D 平面载体（画面里不得出现 3D 立体字）
  - 巨型标语 + 副标 + 哲学引言 + 角色档案条
  - 场景内的次级涂鸦
  - 四角 HUD 装饰与角色档案条（识别件，不得省略）
  - 一个色相统治全图（不是"深色底 + 点缀色"）
  - 标语被人物的身体或前景物体切断
  - 人物偏置到一角（不居中）
  - 强广角透视 + 背景参与构图
  - 动态姿态与能量焦点
avoid_when_applying_to_keyvisual:
  - 3D 立体字（最土的形式）
  - 安全构图：人物居中 / 中轴对称 / 字与人分区不交叠 / 标语完整不被切 / 背景纯剪影或空景 / 中焦平视
  - "深色底 + 局部点缀色"的配色（整体偏灰，角色跳不出来）
  - 外文品牌名水印、左上角 nameplate、真实赛事或游戏 Logo
  - 缺 HUD 或角色档案条
  - 低饱和、平光、静态站姿摆拍
  - 中文标语（画面文字全英）
avoid_when_applying_to_sheet:
  - 网格线、边框、角标
  - 各格配色或 HUD 语言不一致
  - 把不同姿态做成不同成像
```
