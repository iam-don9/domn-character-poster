# 时尚大刊封面（fashion-masthead）

## 视觉风格原子

一张高定时装大刊封面：满幅时装摄影打底，顶部一条超大高对比衬线刊名横贯，两侧细窄封面线，底部期号与条码位——整体是"刊物"，不是单张画。

> 视觉 DNA 来自**高定时装大刊那一系**：极细 × 极粗笔画强对比的 Didot / Bodoni 衬线刊名 + 满幅时装摄影 + 两侧细窄封面线。
> **刊名一律用虚构刊名承载**——任何真实刊名 / 报头 / 媒体品牌名都会被模型画成左上角 nameplate，且多为注册商标，**禁止写进 prompt**。

## 输入变量

- 角色：{{角色名 / 角色组名}}
- 角色设定摘要：{{...}}
- 画幅比例：3:4
- 语言：English
- 点缀：{{不使用 / 期号条}}

## 风格基因

### 版式

- 刊名区：顶部横贯，占画面高约 18%–25%，横向占宽 **≥75%**；字距紧、字腔小。
- 主体区：中段满幅，主体可越过刊名区下缘（人物遮住部分刊名是封面惯例）。
- 封面线：左右两侧各 1–2 条，窄体无衬线，字级明显小于刊名。
- 信息区：底部边角放期号 / 日期 / 条码位。

### 构图与分区

- 主体满幅、顶天立地；头部不等高、前后错落景深。
- 三层：刊名区 / 主体区 / 信息区，层级清楚。
- 封面线围绕主体、不侵入脸部。
- **多人组像**：前排至大腿、中排至腰、后排仅头肩，互相轻微遮挡——用景深分层替代网格分格。

### 字体

- 刊名：**极细笔画 × 极粗笔画强对比的 Didot / Bodoni 式衬线**，全大写，字距紧。
- 封面线：窄体无衬线小字。
- 期号 / 日期：最小号，等宽。

### 图文关系

- 刊名可被主体头部遮挡一部分，但**刊名主体仍可读**。
- 封面线**不遮脸、不遮标志物**。

### 色彩系统

- 背景：冷调影棚灰到冷白渐变，或与主体强对比的纯色。
- 强调色：**最多一种**，只用在刊名或一条封面线上。
- 整体统一，不与角色配色抢——**不写角色配色**。

### 装饰元素

- 期号条 / 日期 / 条码位 / 一条细分隔线，总面积 **≤5%**。

## 生成前检查

- 刊名区是否够大、够醒目（横向 ≥75%）？
- 刊名是否为高对比衬线、全大写？
- 封面线是否每侧 1–2 条、不遮脸？
- 是否**没有出现任何真实刊名 / 报头 / 品牌名水印**？
- 强调色是否只有一种？
- **为什么这是最抓眼球、最有张力的形式？**——答：满幅时装摄影 + 顶部压顶的巨型衬线刊名，形成"人被刊物吞掉"的比例张力；这是唯一能把多个角色同时压进同一视觉系统的排法。

## 风格特有禁用项

- **不要真实杂志 / 报纸名、不要报头 nameplate、不要外文品牌水印**（最高优先禁令）。
- 不要做成一张普通插画（必须有刊名区 + 封面线，才成立）。
- 不要每侧超过 2 条封面线、不要让封面线遮脸。
- 不要多种强调色、不要霓虹发光、**不要 3D 立体字**。
- 不要网格线 / 分格边框 / 编号标签（多人组像用景深分层，不用格子）。
