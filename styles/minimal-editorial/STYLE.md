# 极简编辑式

## 视觉风格原子

一张克制的研究出版物式海报：纯色背景、大面积留白、一块衬线主标题、角色作为唯一视觉中心，配 2–4 个无功能平衡色块。保持编辑感，不做商业广告。

## 输入变量

- 角色：{{角色名}}
- 角色设定摘要：{{...}}
- 画幅比例：3:4
- 语言：English
- 背景方案：{{A 陶土橙 / B 深黑 / C 暖灰 / D 鼠尾草绿 / E 雾霾蓝；未指定用 A}}
- 点缀：{{不使用 / 一条细分隔线}}

## 风格基因

### 版式

- 大面积留白；主标题是第一视觉，也是画面的结构中心。
- 默认只显示一个主标题；有称号时最多加一行，字级更低。
- 不加栏目标签、页码、日期、网址或无意义说明。

### 构图与分区

- 主标题 + 角色主体 + 留白共同构成**唯一视觉中心**。
- 角色不作满构图：占画面高约 55%–70%，四周留出呼吸空间。
- 不把画面切成多个信息区。

### 字体

- 主标题：高对比衬线，参考研究杂志标题的粗细变化与书籍感。
- 辅助文字：简洁无衬线；等宽字体只用于少量结构文字。
- 不堆叠字体，不做产品发布会口号式标题。

### 图文关系

- 标题、角色、留白共处一个视觉中心，不把标题贴在无关背景上。
- 装饰元素可接近或回应标题，但**不遮挡标题、不遮脸**。

### 色彩系统

- 每张只用一个背景方案，不随机切换：
  - A 背景 `#D97757` / 文字 `#1A1A1A`
  - B 背景 `#1A1A1A` / 文字 `#EFEAE0`
  - C 背景 `#D8D5CF` / 文字 `#1A1A1A`
  - D 背景 `#B8C9B8` / 文字 `#1A1A1A`
  - E 背景 `#8FA9C7` / 文字 `#1A1A1A`
- 背景保持大面积纯色，不渐变、不霓虹、不发光。

### 装饰元素

- 2–4 个无功能色块，只用于平衡构图，**总面积 ≤5%**。
- 可取自 `#EFEAE0` / `#CD6F47` / `#6B8A6F` / `#8FA9C7` / `#1A1A1A`。
- 不均匀排列、不做成 UI 按钮、不形成大量散点。

## 生成前检查

- 是否只有一个主标题、一个视觉中心？
- 是否使用**一个**固定纯色背景方案？
- 是否保留足够留白？
- 装饰是否只有 2–4 个、总面积 ≤5%？
- 是否没有品牌 Logo、署名、页码、日期或无意义说明？
- 是否没有渐变、霓虹、3D、商业模板感？

## 风格特有禁用项

- 不要复制任何机构的 Logo、字标、品牌署名或固定官方版式。
- 不要商业广告、发布会视觉、PPT 封面。
- 不要复杂信息图、大量文字、3D、渐变、霓虹、发光。
- 不要多种强调色、均匀装饰阵列、UI 按钮状元素。
