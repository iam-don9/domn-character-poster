# domn-character-poster

> 独立技能仓库 · 来自 domn skills 集合（视觉图像 域）

"原创角色宣传物料生成器。输入用户提供的角色参考图（多张按用途分工），按用户指定的方向出图（当前两档：keyvisual 主视觉海报 / sheet 人物设定图，方向可扩展；两个都要则分两次生成）。三条互不越界的轴：①角色成像与长相由参考图锁死（角色锚点卡）②角色在做什么（姿态/情境/机位角度）由演出库 staging/ 决定③海报的版式/字体/图文关系由画风库 styles/ 的「海报视觉原子」决定；优先级 角色锁定 > 演出 > 海报风格。原子与方向的适配按判定规则执行时现判。两个库都先查库、命中直接套用，未命中按方法现生成。画面文字全英。关键词：角色海报、角色展示图、人物设定图、设定集、角色设定图、原创角色、角色 key visual、海报视觉原子、画风库、演出库、动作指导、姿态、角色锚点卡、i2i 锁形、角色宣传物料、character poster、character sheet、poster layout style、pose、staging。" --- # domn-character-poster 角色宣传物料 把用户提供的**角色参考图**，按用户指定的方向出图：`keyvisual` 主视觉海报 / `sheet` 人物设定图。 **角色长什么样由参考图锁死，海报怎么排由画风库决定——两者不得互相污染。** ## 何时使用 - 给原创角色出宣传物料（海报 / 展示图） - 已有角色参考图，要保证多张里是同一张脸、同一套画风 - 要把一种**海报排版风格**沉淀进画风库 不适用：无参考图的角色（停下要求提供）、只写一条无结构的单图 prompt、视频分镜、角色/道具资产卡拆分。 ## 三条互不越界的轴（先内化） | 轴 | 来源 | 管什么 | 优先级 | 谁**不许**重写 | |---|---|---|---|---| | **① 角色锁定** | 参考图（i2i + 角色锚点卡） | 成像 5 维（媒介 / 笔触 / 上色 / 光照 / 材质）+ 视觉锚点 7 项（面容 / 头面部附属 / 体型与身体 / 服装 / 武器与装备 / 配色 / 标志物）；**锚点深度按角色复杂度选**（简 / 中 / 复杂 / 极复杂） | **最高** | 演出库、海报风格 | | **② 演出** | 演出库 `staging/` | 姿态与肢体语言 / 手部动作 / 表情与视线 / 情境 / **机位角度** | 中 | 海报风格 | | **③ 海报风格** | 画风库 `styles/` | 版式 / 构图分区 / 字体 / 图文关系 / 背景色彩氛围 / 装饰元素 | 最低 | 骨架类只引用、演出库 | | 画幅 / 降噪后缀 | `config.md` | — | — | 全部 | **冲突时按优先级裁决：** - 海报风格原子**不得**改变角色本体的成像与角色配色——那是参考图的职责。 - **角度归演出，占比归海报风格**：演出管机位与角度（仰 / 俯 / 平、正 / 侧 / 背、透视强度），海报风格管版面占位（角色占画面比例、标题位、留白）。 - "在做什么"是内容，优先于形式；但受海报风格的**版面裁剪**（可缩小占比，不可改姿态）。 ## 拒绝平庸安全（强制自证） **这是设计原则，先于一切规则。** 每个关键选择——**演出 / 海报风格 / 构图 / 字体 / 色温 / 标语布局**——都必须能回答一句： > **「为什么这是最抓眼球、最有张力的那个？」** **答不出 → 重选。** 不许默认选最稳的。 **默 …（完整说明见 SKILL.md）
